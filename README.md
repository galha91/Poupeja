# PoupeJá — Assistente de Poupança para Portugal

![PoupeJá](https://img.shields.io/badge/Next.js-14-blue?style=flat-square) ![React](https://img.shields.io/badge/React-18-cyan?style=flat-square) ![Tailwind](https://img.shields.io/badge/Tailwind-3-38B6FF?style=flat-square)

A plataforma #1 de poupança inteligente em Portugal. Compara preços, recebe alertas, acompanha cartões de fidelização e poupa com a família.

## 🎯 Funcionalidades Exclusivas

### 🧺 Cesto Inteligente
Adiciona produtos ao carrinho virtual e descobre em qual supermercado (Continente, Pingo Doce, Lidl, Aldi, Intermarché) o teu cesto fica mais barato.

### 📸 Leitura de Talão com IA
Fotografa o teu talão e a IA Claude calcula quanto podias ter poupado comprando noutro supermercado.

### 🔔 Alertas de Preço
Define o preço máximo que queres pagar. Somos notificados quando um produto baixar para o teu alvo.

### 💳 Cartões de Fidelização
Todos os teus cartões (Continente, Poupa Mais, FNAC, Worten) num só lugar. Acompanha pontos, cashback e benefícios.

### 👨‍👩‍👧 Modo Família
Orçamento partilhado do agregado familiar. Cada membro tem objetivos de poupança e vê o impacto das despesas compartilhadas.

## 📊 Seções Principais

| Secção | Funcionalidades |
|--------|-----------------|
| **🛒 Mercados** | Promoções semanais · Cesto inteligente · Leitura de talão · Comparador |
| **🛍️ Lojas** | Moda (Zara, H&M, Mango, etc.) · Eletrónica (Fnac, Worten, MediaMarkt, etc.) |
| **⛽ Mobilidade** | Preços combustíveis (DGEG) · Postos EV (MOBI.E) |
| **💶 Poupança** | Dashboard · Alertas de preço · Cartões de fidelização · Modo família |

## 🛠️ Stack Técnica

- **Frontend:** React 18 + Next.js 14
- **Styling:** Tailwind CSS 3
- **Fonts:** Sora (títulos) + DM Sans (corpo)
- **IA:** Claude Sonnet 4 (análise de talões)
- **APIs:** Clearbit (logos) · Google Fonts
